# Experiment Learning AI

A hands-on collection of experiments while learning and building **LLM and Agentic AI applications**.

## 🎯 Purpose

This repository is my engineering playground for learning AI by building working implementations rather than only studying concepts.

## 🧠 Topics

- LLM applications
- Prompt engineering
- LangChain
- LangGraph
- Tool calling
- Agents
- Memory
- Structured outputs
- RAG
- Embeddings
- Vector databases
- Exception handling and retries
- AI application patterns

## 📁 Approach

Each experiment focuses on one concept and turns it into executable code.

> Learn → Build → Break → Debug → Improve

## 🚀 Getting Started

```bash
git clone https://github.com/imvimalsharma/Experiment_Learning_AI.git
cd Experiment_Learning_AI
```

Install the dependencies required by the individual project or notebook.
